# سجل الترقية البصرية السيادية — LIJAN™
## Sovereign UI/UX Upgrade Register

**النطاق (Scope):** طبقة العرض فقط — الرموز البصرية (tokens) والمكوّنات المشتركة والهيكل العام.
**ما لم يُمس (Untouched):** سير العمل · البيانات · الصلاحيات · RLS · الوظائف الخلفية · الهوية البصرية · الخط Noto Naskh Arabic · المسارات.
**الإصدار (Release):** لم تُنشَر — الترقية داخل المحرر فقط حتى اعتماد بصري.

## ١. الرموز الموحّدة — قبل / بعد

| الرمز (Token) | قبل (Before) | بعد (After) |
|---|---|---|
| `--radius` | `0.375rem` | `0.5rem` |
| `--card-radius` | `20px` | `18px` |
| `--card-shadow` | ظلّان مارونيان مفردان | `var(--elevation-1)` |
| `--card-shadow-hover` | ظلّان مفردان أعمق | `var(--elevation-3)` |
| `--elevation-1/2/3` | — | ثلاثة مستويات فقط: ساكن · مرفوع · طافٍ |
| `--elevation-overlay` | — | ظلّ النوافذ والحوارات `0 24px 64px` |
| `--ease-sovereign` | `cubic-bezier(0.4,0,0.2,1)` | `cubic-bezier(0.32,0.72,0,1)` |
| `--dur-fast/base/slow` | — | `140ms · 220ms · 320ms` |
| `--leading-display/heading/body/label` | — | `1.1 · 1.25 · 1.6 · 1.35` |
| `--tracking-display/heading` | — | `-0.022em · -0.012em` (لاتيني فقط) |

**الظل الواحد لكل سطح:** لا يُرفع سطح بمقدار درجتين؛ الحالة (ساكن · تحويم · طافٍ) هي التي تحدّد الدرجة.
**الحركة:** منحنى واحد وثلاث مدد — لا منحنيات ولا أزمنة متفرقة في أي شاشة.
**التتبّع (tracking):** مقصور على العناوين اللاتينية عبر `[dir="ltr"]` — العربية تبقى `letter-spacing: 0` كما يفرض عقد الطباعة.

## ٢. المكوّنات المشتركة — العقد الموحّد

| المكوّن | ما تغيّر |
|---|---|
| `button` | نصف قطر `rounded-lg` · ظلٌّ `elevation-1` · حلقة تركيز 2px بإزاحة · `active:scale-[0.99]` · تحويم على `primary-dark` · `lg` = 44px |
| `card` | `rounded-[var(--card-radius)]` · حدّ صريح · `elevation-1` · عنوان `text-base` · وصف `leading-relaxed` |
| `input` / `textarea` | ارتفاع 40px · `rounded-lg` · خلفية `card` · حدّ عند التركيز + حلقة 2px · حشو مريح |
| `label` | حبر `foreground/90` — تمييز أهدأ عن قيمة الحقل |
| `badge` | كبسولة `rounded-full` · وزن `semibold` · ظلّ `elevation-1` |
| `tabs` | مسار كبسولي على `secondary` · تبويب نشط `card` + `elevation-1` · حركة `ease-sovereign` |
| `table` | رأس 44px بحبر مصغّر `11px` وأحرف كبيرة · محاذاة منطقية `text-start`/`pe-0` (RTL/LTR) · صفوف `py-2.5` · تحويم هادئ |
| `dialog` | حاجب `foreground/45` مع ضباب خفيف · لوح `card` بحدّ `elevation-overlay` · حشو 20px · `duration 220ms` |
| `PageHeader` | عنوان `text-xl` بوزن 700 · سطر سندي `leading-relaxed` · فاصل ومسافات موحّدة (`mb-5 pb-4`) |
| `StatusBadge` | كبسولة واحدة بحشو 10px — الحالة تُقرأ بنفس الشكل في البطاقة والجدول والملف |

## ٣. الاتجاه والوصولية (RTL/LTR · A11y)

- الازدواجية محفوظة: كل ما هو منطقي (`text-start`, `pe-0`, `border-inline-start`) بدل الاتجاهي.
- حلقة التركيز موحّدة `2px` بإزاحة `2px` على الزر والحقل والتبويب والنافذة.
- `aria-hidden` والحدود الدنيا للمس (44px) لم تُمس، وزر `lg` صار 44px فعلًا.
- العربية: لا تتبّع ولا ظلّ نصّي ولا وزن مصطنع — كما كان.

## ٣-ب. المادة الزجاجية العائمة (Hajar Wahid Glass)

| العنصر | ما أُضيف |
|---|---|
| الرموز | `--glass-surface` · `--glass-surface-strong` · `--glass-border` · `--glass-highlight` · `--glass-blur` — قيم لون كاملة (لا `hsl(var())`)، ولها نظير في `.dark` |
| المادة | لوح شفّاف + حدّ شعري + وميض واحد على الحافة العليا + `backdrop-filter: blur(14px)` |
| الرمز المطابق | `bg-glass` · `bg-glass-strong` · `border-glass` · `backdrop-blur-glass` · `raqeem-card` |
| الطفو | `sovereign-levitate`: ٣ بكسل على ٩ ثوانٍ عبر خاصية `translate` — فلا تتعارض مع ارتفاع التحويم الذي يستخدم `transform` |
| إيقاع الشبكة | البطاقات المتجاورة تهتزّ خارج الطور (`nth-of-type`) فتبدو الشبكة تتنفّس لا تنبض ككتلة واحدة |
| التحويم | المادة تُكثَّف (`--glass-surface-strong`) والسطح يرتفع — والطفو يتوقف |
| الحدود | لا طفو داخل النوافذ واللوحات الطافية (`[role=dialog]` ومحتوى popper)، ولا طفو مع `prefers-reduced-motion` |
| النطاق | `raqeem-card` (٣٧٥ موضعًا في ١٤٧ ملفًا) + `ui/card` + `SovereignCard` — تعديل واحد يصل إلى كل صفحة |

## ٣-ج. الجداول والنماذج داخل الوحدات — الدفعة الأولى

| العنصر | ما أُنجز |
|---|---|
| الجداول | الجدولان الخام الوحيدان داخل الوحدات نُقلا إلى عقد `ui/table` الموحّد: `CommitteeRoles` (وأُصلحت محاذاته: `text-start` بدل `text-right` الثابتة) و«جدول المقارنة» في `LegislativeFileDetail` |
| ضوابط النماذج | موحّدة مركزيًا في `input` · `textarea` · `select`: `rounded-control` وارتفاع ٤٠px وحلقة تركيز ٢px وانتقال `ease-sovereign` |
| نموذج الوحدات المشترك | `CrudFormDialog` (يخدم ١٣ شاشة) أُعيد ضبطه: قائمة اختيار بعقد الضوابط الموحّد بدل `h-9 rounded-md bg-transparent`، وإيقاع حقول `space-y-1.5` وشبكة `gap-4` وحشو `p-5` |

## ٤. المؤجَّل صراحةً (Deferred)

1. بقية شاشات الوحدات (~50 سطحًا) التي تبني حقولها بنفسها — مراجعة شاشة-بشاشة لضبط الإيقاع على عقد `CrudFormDialog`.
2. النوافذ واللوحات الطافية (dialog · sheet · popover · dropdown) لم تلبس المادة الزجاجية بعد.
3. الحوارات المتعدّدة الخطوات داخل الوحدات.
4. حزمة الأدلة البصرية «قبل/بعد» للرحلات المفتاحية — عبر وكيل الاختبار (لقطات)، إذ لا تُنتَج اللقطات من داخل المحرر.

## ٥. حالة التحقق (Verification)

| الفحص | الحالة |
|---|---|
| بناء الواجهة (Vite build) | **ناجح** — لا أخطاء |
| حرّاس اللغة (`lang-guard`, `lang-check`) | مُنفَّذان — لا إخلال في قوائم الحالة، والملاحظات المكتشفة سابقة لهذا التغيير (نصوص نماذج) |
| طبقة `ui/` المشتركة | **موحّدة بالكامل** — صفر ظلّ قديم (`shadow-sm/md/lg/xl`) في أي مكوّن مشترك |
| الظلال في المنصة كلها | **مُنجَز** — صفر ظلّ قديم في `components/` و `pages/`؛ كل رفع عبر `elevation-*` |
| ألوان Tailwind الخام في أسطح الدخول | **مُنجَز** — `AuthLayout` و`UserNotRegisteredError` على رموز المنصة وحدها |
| طبقة الطباعة التنفيذية | مطبَّقة على ترويسة الصفحة والحالة الفارغة وترويسة الدخول |
| تحقّق بصري لرحلات مفتاحية (رئيسية · لجنة · اجتماع · قرار · تصدير) | **معلَّق** — بانتظار وكيل الاختبار |
| نشر | **لم يُنشر** (بناءً على الطلب) |
