### 1.2 ما لا تستوعبه المسارات الحالية (إثبات الحاجة)

1. **لا يوجد كيان يمثّل «الملف التشريعي» كخط زمني متصل** من الإحالة إلى التسليم. `Decision` يلتقط قرارًا واحدًا، و`Meeting` يلتقط اجتماعًا، و`Document` يلتقط وثيقة — لكن لا شيء يربط: إحالة → لجنة → اجتماعات → تعديلات → تقرير → تصويت → اعتماد → تسليم → متابعة → إغلاق في سجل واحد قابل للمتابعة. **يبرر كيانًا جديدًا: `LegislativeFile`.**

2. **لا يوجد «نموذج تشغيل» قابل للتهيئة لكل جهة.** `GovernanceConfig` عالمي (config_key) ولا يحمل ملف تشغيل لكل جهة يفعّل المفردات التشريعية ودورة الملف. **يبرر كيانًا جديدًا: `LegislativeProfile`.**

3. **`Meeting` لا يحمل حقول جلسة الاستماع** (الجهة المستدعاة، الأسئلة المعتمدة، الإفادة، ما استخلصته اللجنة). إضافة الحقول إلى `Meeting` تلوّثه. **يبرر كيانًا جديدًا: `HearingSession`** مرتبط بـ `Meeting` و `LegislativeFile`.

4. **جدول مقارنة النصوص** (المحال/المقترح/ملاحظات اللجنة/الصياغة النهائية) — يمكن تضمينه كحقل مهيكل في `LegislativeFile` في المرحلة الأولى.

5. **تقرير اللجنة** — `ProductTemplate` يدعم `committee_report` و`template_structure`، و`Document` يحمل الوثيقة. دورة حياة التقرير التشريعي (مسودة→مراجعة→تعديلات مطلوبة→معاد التقديم→معتمد→صادر→معدل بإصدار جديد→مؤرشف) قابلة للتمثيل عبر `Document.status` + حقل `report_stage`. في المرحلة الأولى نُمثّل التقرير كـ `Document` من نوع `report` مرتبط بالملف، ونؤجل كيانًا مستقلًا إن لزم.

## 2. الكيانات الجديدة ومسؤولية كل كيان

| الكيان | المسؤولية المؤسسية المستقلة | لماذا لا يكفي موجود |
|---|---|---|
| `LegislativeProfile` | نموذج تشغيل المجلس التشريعي لكل جهة (تفعيل المفردات، تصنيف الموضوعات، قنوات التسليم، وضع التكامل) | `GovernanceConfig` عالمي ولا يحمل ملفًا لكل جهة |
| `LegislativeFile` | الملف التشريعي الموحد: الخط الزمني المتصل من الإحالة إلى الإغلاق | لا يوجد كيان يربط الإحالة بالتسليم والمتابعة |
| `HearingSession` | جلسة الاستماع كنوع مستمر مرتبط بالملف | `Meeting` لا يحمل حقول الاستماع |

## 4. قواعد عدم الادعاء (مطبّقة)

- لا ادّعاء اعتماد مجلس الشورى.
- لا شعار المجلس دون أصل مصرح.
- لا ادّعاء تكامل قبل اختباره — وضع التكامل الافتراضي: `manual_governed_handoff`.
- لا أصوات/توقيعات/اعتمادات تاريخية مختلقة.
- بيانات العرض ليست بيانات رسمية — تُنشأ داخل نطاق Showcase معزول (is_demo_data=true, demo_dataset).
- لا تعديل لبيانات الإنتاج أو عضويات الدكتور حمد أو لجانه السبع.

---

## 5. نقطة الاسترجاع

- لم تُعدّل بيانات الإنتاج.
- لم تُمسس عضويات الدكتور حمد أو لجانه السبع.
- كل إضافة في نطاق Showcase معزول عند العرض التشريعي.
- البناء ناجح هو شرط لازم لا كافٍ — القبول الوظيفي يأتي بعد اختبارات المرحلة 15.

**هذه النقطة هي المرجع قبل أي تعديل لاحق.**
