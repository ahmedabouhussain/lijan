# سجل المنافسة | COMPETITIVE REGISTER — LIJAN™

**الغرض**: تثبيت أرضية التكافؤ، والادّعاء المقترح لكل محور، والاختبار القابل للمقارنة، قبل أي قياس. هذا السجل **بلا نتيجة اليوم**: لا قياس أُجري على LIJAN ولا على أي منتج منافس بأيدٍ (لا حساب منافس، لا تجربة مدفوعة، لا إرسال بيانات).

## 1. قواعد الإثبات (ملزمة)

1. **مصدر المنافس = قدرة مُعلَنة/موثَّقة**، وليس أداءً ناجحًا مُختبَرًا. غياب التوثيق العام = **مجهول**، لا «غائب».
2. **لا دمج منتجات**: كل صف يُقارن بالمنتج/الإصدار المحدد وأي إضافات فعلية؛ لا SKU وهمي مركَّب.
3. تصنيف كل قدرة: `native` · `configured` · `integrated` · `custom-built` · `غير متاح للفحص`.
4. المسار الحالي للعمل لدى الجهة المشترية (أو بناء داخلي على Power Platform/Dataverse) **مقارن معتبر** مثل أي منتج مدرج.
5. **الحكم الافتراضي حتى التنفيذ**: «LIJAN مُدلَّل عليه؛ التفوّق المقارن غير مُختبَر». ولا يُرتَّب `leads / parity / trails` إلا بعد تنفيذ نفس المهمة بنفس البيانات والأدوار والعبء.
6. لا تُختلق نسب توفير أو ترتيب أو سعة. أهداف التحسين تُحدَّد **بعد** ملاحظة خط الأساس وأولويات المشتري.
7. **السلطة والسلامة والخصوصية شرط pass/fail إلزامي**: مهمة أسرع لا تعوّض وصولًا غير مخوّل أو سجلًا رسميًا كاذبًا.
