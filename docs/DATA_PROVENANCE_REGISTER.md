## القواعد الملزمة المطبَّقة

1. لا يُنشأ تاريخ مؤسسي لاجتماع حقيقي بلا مصدر معتمد — المحتوى المولَّد يُصنَّف «مولَّد» ويُعلَن.

3. لا أحداث تدقيق بتاريخ رجعي: كل حدث تدقيق يحمل وقت تنفيذه الحقيقي.
4. لا حذف نهائي لسجلات مؤسسية — الأرشفة قابلة للاسترجاع.
5. البيانات المختلقة لا تُستخدم وسيلةً لنجاح اختبار.
